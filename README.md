## Structure 📂

Each exercise lives in its own folder with a concise summary:

* **ex00 – Oh yeah, mooore...**: introductory C commands and basic output.
* **ex01 – Z**: print a ‘Z’ pattern using characters.
* **ex02 – clean**: implement a function to clear memory or buffers.
* **ex03 – find\_sh**: search for substrings within strings.
* **ex04 – MAC**: calculate memory address conversions or checksum.
* **ex05 – Can you create it?**: dynamic memory allocation practice.
* **ex06 – ft\_print\_alphabet**: display the lowercase alphabet.
* **ex07 – ft\_print\_numbers**: output digits from 0 to 9.
* **ex08 – ft\_is\_negative**: indicate if a number is negative.
* **ex09 – ft\_ft**: write a function to update a value via pointer.
* **ex10 – ft\_swap**: swap two integers.
* **ex11 – ft\_div\_mod**: compute division and modulo through pointers.
* **ex12 – ft\_iterative\_factorial**: factorial via iteration.
* **ex13 – ft\_recursive\_factorial**: factorial via recursion.
* **ex14 – ft\_sqrt**: compute integer square root.
* **ex15 – ft\_putstr**: output a string to stdout.
* **ex16 – ft\_strlen**: return the length of a string.
* **ex17 – ft\_strcmp**: compare two strings lexicographically.
* **ex18 – ft\_print\_params**: print program arguments.
* **ex19 – ft\_sort\_params**: sort and display program arguments.
* **ex20 – ft\_strdup**: duplicate a string with malloc.
* **ex21 – ft\_range**: create an array range between two ints.
* **ex22 – ft\_abs.h**: header-only absolute value macro/function.
* **ex23 – ft\_point.h**: define and use a point structure.
* **ex24 – Makefile**: craft a Makefile for builds.
* **ex25 – ft\_foreach**: apply a function to each array element.
* **ex26 – ft\_count\_if**: count elements matching a condition.
* **ex27 – display\_file**: read and display a file’s contents.
